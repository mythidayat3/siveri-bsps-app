# Templates Directory

Place the following template files in this directory:

1. **INVERS.xlsx** - Template for INVERS data upload
2. **TEMPLATE_TERVERIFIKASI.xlsx** - Template for verified data upload
3. **FORMAT BERITA ACARA.docx** - Word template for Berita Acara document
4. **SURAT PENYAMPAIAN BA.docx** - Word template for Surat Penyampaian BA

These files are used by the backend to generate exports and provide template downloads to users.
